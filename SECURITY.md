# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities in the SOC-Tools source code privately through
[GitHub Security Advisories](https://github.com/Bananenbaas/soc-tools/security/advisories/new).
Do not open a public issue for a security problem.

This reporting channel covers the project's source code. For a problem with a
specific hosted or deployed instance, contact that site's operator using its
`/.well-known/security.txt`.

See [THREAT_MODEL.md](THREAT_MODEL.md) for the project's security boundaries and
what is in and out of scope.
